# Compatibilidad Firefox/WebKit

El punto 1 prepara la matriz y comprueba el arranque de los motores.
Los casos funcionales SQL/pandas se añaden a partir del punto 2 del
[SDD](../../specs/browser-compatibility-sdd.md).

No se incluyen pruebas vacías, omitidas o respuestas de motores simulados para
presentar esta preparación como compatibilidad de la aplicación.
